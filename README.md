\# AI Spam Message Classifier



A machine learning project that classifies SMS messages as \*\*Spam\*\* or \*\*Not Spam (Ham)\*\*.



\## Project Overview



Spam messages can contain unwanted advertisements, fraudulent offers, suspicious links, or other unwanted content.



This project uses Natural Language Processing and Machine Learning to automatically classify SMS messages.



The system provides a simple web interface where a user can enter a message and receive a prediction.



\## Features



\- SMS spam classification

\- TF-IDF text feature extraction

\- Multinomial Naive Bayes machine learning model

\- Model evaluation using multiple metrics

\- Saved trained model

\- Simple Streamlit web interface

\- Real-time message prediction



\## Technologies Used



\- Python

\- Pandas

\- Scikit-learn

\- Joblib

\- Streamlit

\- TF-IDF

\- Multinomial Naive Bayes



\## Dataset



The project uses the SMS Spam Collection dataset.



The dataset contains:



\- 5,572 SMS messages

\- Two classes: ham and spam
